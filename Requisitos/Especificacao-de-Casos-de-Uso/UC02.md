## 1. Nome do caso de uso
Realizar autoavaliação de elegibilidade (UC02)

## 2. Objetivo
Permitir ao ator realizar a ação descrita em realizar autoavaliação de elegibilidade, conforme RF03, RN01, US02.

## 3. Tipo
Concreto (proposto).

## 4. Atores
- **Primário:** Estudante
- **Secundário / interação relacionada:** Sistema acadêmico — integração pendente (TBC-02)

## 5. Pré-condições
Estudante autenticado

## 6. Fluxo principal
1. **P1:** O estudante solicita autoavaliação.
2. **P2:** O sistema obtém matrícula, percentual concluído, média e situação de reprovações.
3. **P3:** O sistema compara os dados aos critérios RN01.
4. **P4:** O sistema apresenta o resultado e os critérios avaliados.

## 7. Fluxos alternativos
- A1 (P4): quando algum critério falha, o sistema exibe Não apto e informa os critérios e valores.

## 8. Fluxos de exceção
- E1 (P2): quando a fonte de dados está indisponível, o sistema informa o problema e orienta procurar o NEI ou tentar novamente.

## 9. Pós-condições
O resultado e sua data ficam registrados conforme proposta original.
