## 🎯 Sobre o Projeto
Este projeto tem como objetivo especificar um sistema web/mobile para a gestão da mobilidade acadêmica internacional, alinhado às diretrizes do Núcleo de Estratégias Internacionais (NEI) da Unifor. A solução busca centralizar o acesso a mais de 140 instituições parceiras em 30 países, otimizando os processos de seleção, preparação cultural/linguística, acompanhamento de editais e pós-intercâmbio.

## 📦 Entregáveis do Projeto (`/Requisitos`)
A documentação do projeto está organizados nos seguintes artefatos:
1. **Documento de Visão:** Definição do problema, escopo e público-alvo.
2. **Identificação de Stakeholders:** Mapeamento dos atores diretos e indiretos.
3. **Roteiro e Resultados de Entrevistas:** Elicitação de requisitos com alunos e equipe NEI.
4. **Especificação SRS:** Requisitos Funcionais (RF), Não Funcionais (RNF) e Regras de Negócio (RN).
5. **Backlog Priorizado:** Histórias de usuário organizadas por valor de negócio.
6. **Modelagem UML:** Diagramas de Casos de Uso, Componentes e Implantação.
