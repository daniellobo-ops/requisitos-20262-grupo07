# 📖 Glossário

| Termo | Definição |
| :--- | :--- |
| **Aluno estrangeiro (incoming)** | Estudante de instituição parceira estrangeira que realiza mobilidade na Unifor. |
| **Aproveitamento de créditos** | Reconhecimento, pelo curso de origem, das disciplinas cursadas no exterior, validado pelo coordenador de curso. |
| **Bolsa** | Auxílio financeiro vinculado a um edital ou convênio para estudantes selecionados. |
| **Candidatura** | Inscrição de um estudante em um edital, composta por dados e documentos. |
| **Convênio** | Acordo de cooperação entre a Unifor e uma instituição parceira, que define áreas, vagas e vigência. |
| **Edital** | Documento oficial que abre o processo seletivo e define prazos, requisitos, documentos e vagas. |
| **Elegibilidade** | Situação do estudante que atende aos critérios acadêmicos para se candidatar (RN01). |
| **Elicitação** | Atividade de levantamento de requisitos junto aos interessados (entrevistas, questionários, análise documental). |
| **Intercâmbio / mobilidade acadêmica** | Período de estudo em instituição parceira no exterior. |
| **LGPD** | Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018). |
| **MoSCoW** | Técnica de priorização: *Must*, *Should*, *Could*, *Won't have*. |
| **MVP** | Produto mínimo viável: conjunto menor de funcionalidades que já entrega valor. |
| **NEI** | Núcleo de Estratégias Internacionais da Unifor. |
| **Outgoing** | Estudante da Unifor que realiza mobilidade no exterior. |
| **RF / RNF / RN** | Requisito funcional / requisito não funcional / regra de negócio. |
| **SRS** | *Software Requirements Specification*, a especificação de requisitos de software. |
| **Stakeholder** | Pessoa ou grupo interessado no sistema ou afetado por ele. |
| **Tandem** | Prática de troca de idiomas entre duas pessoas que falam línguas diferentes. |
| **TBC** | *To be confirmed*: pendência a confirmar com os interessados. |
| **UC / US** | Caso de uso / história de usuário. |
| **Wireframe** | Esboço estrutural de uma tela, sem acabamento visual. |
