## A configurar
- Issues e vínculos com requisitos e entregáveis
- Milestones conforme marcos reais da disciplina
- Project/Kanban e Sprints conforme calendário do grupo
- Convenção de commits, política de baseline, revisão por Pull Request

Nenhuma etapa deve ser marcada como concluída antes de sua execução.
